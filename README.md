# 🩺 Diabetes Prediction System

A Machine Learning Based Diabetes Prediction Web Application built using Python and Streamlit.

## 🌐 Live Demo

**Try the application here:**

[Diabetes Prediction System – Live App](https://diabetes-prediction-b9wibatyq3aeukaxhjncda.streamlit.app/)

## 📌 Project Overview

The Diabetes Prediction System uses Machine Learning to predict the likelihood of diabetes based on patient health information.

Users can enter patient details and receive a prediction through an interactive web interface.

## ✨ Features

- Patient information input form
- Machine Learning based prediction
- Interactive Streamlit dashboard
- Prediction result visualization
- About and Model Information sections
- User-friendly interface

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Jupyter Notebook
- Pickle

## ⚙️ Installation and Setup

**1. Clone the repository**

```bash
git clone https://github.com/Raziquebrohi/Diabetes-Prediction.git
```

**2. Open project directory**

```bash
cd Diabetes-Prediction
```

**3. Create virtual environment**

```bash
python -m venv venv
```

**4. Activate environment (Windows)**

```bash
venv\Scripts\activate
```

**5. Install dependencies**

```bash
pip install -r requirements.txt
```

**6. Run the application**

```bash
streamlit run app.py
```

## 📊 Dataset

The project uses a diabetes dataset containing patient health-related attributes for Machine Learning prediction.
